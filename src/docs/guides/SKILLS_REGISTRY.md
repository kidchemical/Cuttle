# Skills

Markdown skills (`SKILL.md`) live under `src/skills/` and `.cursor/skills/`.
They show on the Skills page and are available to agents. Hub/project commands
and actions live under `.cuttle/`.

## API

- **GET /api/skills/markdown** — list markdown skills
- **GET /api/skills/list** — registry entries (templates; install is unused)

The Skills page lists markdown skills. Registry “Install” that wrote graph JSON
is not a product path.
