Core routing

How the routing brain is invoked and where unmatched turns go.

Source of truth: src/settings.json → agent_router. Agents can edit the same JSON directly — this page reloads it from disk.

Use cases

Declared routing table — when a turn matches a use case, its targets override the brain. Sorted simple → complex by priority (lower = matched first); the first matching enabled block is applied.

Target health

7-day outcomes per target, plus the quality-regression check ("is it sucking?"). A flagged target is demoted for 30 min and routed around automatically. Computed locally from outcomes your real routed turns already recorded — no scheduled job, no extra tokens, no LLM judge.

Target Attempts Success Task fails Transport Avg ms Feedback Status

Cancellations are never counted as quality evidence. Demotions expire on their own — a target recovers by simply not failing again.

When a frustration phrase is detected, matching prior attempts are flagged locally (free), and this agent re-analyzes the full evidence in the background — in parallel, so your escalated task never waits for it.
