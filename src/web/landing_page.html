ℹ️ About Cuttle

AI-Powered Multi-Modal PC Control System for Developers

🐙 "AI That Goes Where You Go"

The only PC control system with true multi-modal access

Named after the intelligent cuttlefish, Cuttle adapts to your workflow through multiple interfaces - just as a cuttlefish adapts to different environments.

🦑 What is Cuttle?

Cuttle is an intelligent PC control and development automation platform that gives you and your team seamless access to your development environment from anywhere, through multiple interfaces.

Unlike traditional AI assistants that are limited to single interfaces, Cuttle provides true multi-modal access - control your PC from Discord, web browsers, or command line, with seamless context sharing across all interfaces.

🐙 Multi-Modal Access - Your Killer Feature

This is what makes Cuttle unique in the AI development tool space:

💬

Discord agent operations

Optional REST: Agents can read allowlisted channels and post with a human confirm card. There is no inbound Discord DM gateway in Cuttle Core.

  • python -m api.discord_cli (read-only)
  • discord.post with project channel aliases
  • Token in src/.env never starts a gateway process
🌐

Web Interface - Remote Access

Access from anywhere: Control your development PC from your phone, tablet, or any device with a web browser. Perfect for remote work and emergency situations.

  • Mobile-optimized interface
  • Offline capability for basic operations
  • Push notifications for important events
⚡

CLI - Power User Automation

Advanced automation: For power users who need scripting, batch operations, and integration with other tools. Perfect for CI/CD pipelines and automated workflows.

  • Scripting and batch operations
  • Integration with other development tools
  • Headless server operation
