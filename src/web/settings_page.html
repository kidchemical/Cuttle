📋 Setup steps github.com

One-time setup
Create the app once, then paste the three values above.
  1. Create an app at Settings → Developer settings → GitHub Apps → New GitHub App.
  2. Generate a private key on the app page and paste it above.
  3. Install the app on your account (sidebar → Install App) and copy the installation ID from the URL.
  4. Save, then Test connection. New commits made as the app show its badge.
