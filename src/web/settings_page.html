💻 Desktop app

Laptop Electron client
The desktop app can connect to this PC over LAN instead of starting a second Cuttle. Copy electron/dist/win-unpacked to the laptop once, then choose “Connect to Cuttle” and use the same address as Chrome. After that, an Update button appears in the laptop titlebar when this PC has a newer desktop shell. This host PC (Start Cuttle / local mode) does not show that button.
