# Vendored: Inter

Used only by the Studio chat look (`css/studio/studio_tokens.css`, family
name `Cuttle Inter`). Served at `/css/fonts/inter/…` by the existing `/css/`
route, so no network font load is needed.

- Source: `@fontsource/inter` 5.3.0 (static files from Google Fonts, the
  upstream Inter project by Rasmus Andersson / The Inter Project Authors).
- Files: `inter-latin-{400,500,600,700,800}-normal.woff2` (latin subset).
- License: SIL Open Font License 1.1, see `LICENSE-OFL.txt`.

To update: replace the woff2 files from a newer `@fontsource/inter` release
with the same file names, and keep `LICENSE-OFL.txt` next to them.
