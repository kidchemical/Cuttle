About Cuttle

A persistent home for your AI agents

One workspace, multiple agents

Cuttle brings independently installed agent CLIs into a shared chat workspace. Choose an agent, let the router select one, and keep your conversations and projects together.

What you can do

  • Chat with agents in separate panes and steer supported agents while they work.
  • Keep project commands and context alongside your code.
  • Review Git changes, agent activity, usage, and query logs.
  • Run jobs on your connected mesh workers.
  • Use optional Discord agent operations to read and post through REST.

Getting started

  1. Install and sign in to an agent CLI.
  2. Register a project in the Projects app.
  3. Choose an agent in chat or configure the agent router in Settings.
  4. Open Query log to inspect a turn's activity.

Built with

Python, Flask, SQLite, and vanilla JavaScript. Cuttle runs on Linux and Windows, with web and desktop clients.

Cuttle is open source under the MIT license.
