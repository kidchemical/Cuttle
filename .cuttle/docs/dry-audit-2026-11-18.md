# DRY / duplicate-implementation audit — 2026-11-18

Read-only audit of parallel implementations across UI primitives, chips and
pickers, catalog data, frontend helpers, and backend helpers.
Registry of owners: `docs/architecture/canonical-components.md`.

Findings reflect the November 18 snapshot. Recheck the cited code before acting, especially on surfaces changed by the Studio display release.

## High

1. **Model pickers on a stale catalog.** `orchestrator_page.js:360`,
   `shell_spaces.js:1339`, `chat_supervision.js:284` fetch plain `/api/agents`
   (manifest snapshot) instead of `?live_models=1`. Live-only models (today
   `gpt-6.2-sol`, `gpt-6.2-astra`; also most of OpenCode's list) are missing
   from the playbook Temporary agent, Spaces defaults and the supervisor
   picker, though the server accepts them (`check_agent_pin`). Supervision is
   *Studio*. Fix: one URL each with plain fallback; then one shared client
   loader so no picker can pick the snapshot.

## Medium

2. **Spaces effort rule diverges.** `shell_spaces.js:1419-1444` lists the
   `efforts` union, ignores `model_efforts`, and never clears an incompatible
   effort on model change → can store `ultra` with `gpt-5.5`. Fix: use
   `CuttleOrchestrator.pinOptions`.
3. **Supervision drops a live-only pin on save.** `chat_supervision.js:393-405`
   rebuilds selects from the catalog only; a saved model not in it becomes
   "CLI default" and is submitted empty. *Studio.* Fix: live catalog + keep the
   saved value as an option (as `router_editor.js:70-119` does).
4. **Composer effort palettes hard-coded.** `chat_agent_controls.js:2874-2876`
   (`MUSE_/HERMES_/OPENCODE_EFFORT_LEVELS`); the `/effort` endpoints' `levels`
   are discarded and OpenCode per-model variants ignored. *Studio (composer).*
5. **Restart status write race.** `cuttle_daemon.py:800` and
   `flask_restart.py:162` both write `flask_restart_status.json.tmp` from two
   processes. Fix: unique temp name / shared writer (restart-owned; review).
6. **Windows CLI lookup bypasses `which_preferring_native`.** claude, codex,
   hermes, cursor, antigravity executables use bare `shutil.which` → npm
   `.cmd` shims (argument truncation). OpenCode already uses the owner.
7. **Agent-id normalizers disagree.** `agent_defaults.normalize_agent_id` has
   no aliases (`cursor-agent` star stored under the wrong key) vs
   `agent_router.registry`. Fix: one alias table in `agent_harness.catalog`.
8. **Atomic JSON write ~9 variants** (fsync / temp naming / mode differ;
   `agent_router/budget.py` pid-only temp without a lock). Fix: move
   `settings_storage.atomic_write` to `core/`.
9. **Modal behavior split.** Native `<dialog>` (git, projects, agent review)
   vs role-dialog overlays (chip config, IDE quick, mobile, orchestration,
   supervision); focus / Escape differ. `CuttleModal` only toggles visibility.
   Partly *Studio*.
10. **Confirm dialogs.** `window.confirm` in tasks, projects, orchestrator,
    agent profiles, secrets, mesh, gizmos vs the in-page typed-name dialog.
11. **HTML escaping ~14 copies** with different quote/nullish handling
    (attribute-injection risk). Partly *Studio*.
12. **Time/duration formatting ~10 copies.** Partly *Studio* (fleet, voice clip).
13. **Vendor CLI drain loops** (cursor, muse, codex app server, opencode) skip
    `run_interruptible` — timeout/cancel parity *unverified*; trace first.

## Low

- Router fallback lists stale (`agent_router/routes.py:57-64`: `gpt-5-codex`,
  `o4-mini`) — shown only when live load fails.
- Offline fallback differs: chat per-agent routes → manifest; Settings/pins →
  last-good live list (`load_agent_catalog`).
- Cursor model label computed three ways (`web_chat_api.py`, `chat_metadata.py`,
  …) — raw id vs title case. *Studio (bubble header).*
- Spaces project chip never shows the ★ (`isProjectStarred: () => false`).
- Tabs/segmented controls: different ARIA/keyboard contracts. Partly *Studio*.
- Byte formatting ×2, clipboard fallback chat-only, CH- linkify chat-only.
- Desktop/client state dirs bypass `runtime_paths` (`cuttle_client_daemon.py`,
  `cuttle_device_worker.py`) — rule violation.
- Effort vocabularies ×5; SQLite helpers ~30; timestamp helpers ~50; route
  error envelopes unshared.

## Consistent (no action)

Project list (one endpoint, one picker — the old project-chip split is gone),
usage/quota, settings storage, vendor CLI env (`agent_cli_env`), server pin
validation, Markdown rendering.

## Proposed checks

- Quality guard: fail on `/api/agents` fetches without `live_models` in
  `src/web/js/**` outside an allowlist (chat slash overlay, capability read).
- Quality guard: new hand-rolled `esc`/`escapeHtml`/`formatBytes` definitions
  outside the shared owner once one exists (ratchet: current count may not grow).

The registry rule is already in place: `.cuttle/rules/00-core.md` #9 → `canonical-components.md`.
