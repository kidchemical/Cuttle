# Tasks are Gizmos

Tasks are scoped Gizmos above the chat composer. Create and update them through
`python -m api.gizmos tasks` during planning and work, not markdown at the end
of a response. Procedures and attribution: [gizmos.md](gizmos.md).

Existing task records and `api.widgets_cli` remain compatible. New work uses
the Gizmos interface. Charts and interactive forms remain chat widgets.
