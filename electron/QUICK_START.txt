To create a Windows installer:

Double-click:
  ► build_electron.bat

Choose your build option:
  1. Full Installer (NSIS) - Professional installer
  2. Portable Version - Single .exe file
  3. Both - Create both versions
  4. Directory - Unpacked files for testing

Output location:

⚠ Python not found?
  → Ensure Python 3.8+ is installed and in PATH
  → Run: python --version

⚠ Port 8080 in use?
  → Close other applications using port 8080
  → Or run: python src/kill_bots.py

⚠ Build fails?
  → Delete electron/node_modules
  → Run: npm cache clean --force
  → Run: npm install
  → Try again

⚠ Blank window?
  → Check console for errors
  → Press Ctrl+Shift+I to open DevTools
  → Check if Flask server started
