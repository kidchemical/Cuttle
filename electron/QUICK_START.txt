CUTTLE DESKTOP QUICK START — Windows and Linux

1. Host: install Python 3.11+ and create the root .venv using README.md.
   Install src/requirements/requirements.txt with that venv.
   Client: connect to an existing Host; Python is needed for optional worker mode.
2. Install Node/npm for source development. From electron/: npm ci
3. Choose a mode from electron/:
     npm start -- --mode=host
     npm start -- --mode=client
   Linux launchers from the repository root:
     ./.cuttle/scripts/launch-cuttle-host.sh
     ./.cuttle/scripts/launch-cuttle-client.sh

Host owns the local daemon. Client connects remotely; enable Phone/LAN access
on the Host first. Electron prefers http://<host>:8000 (trusted LAN only), then
https://<host>:8080 (self-signed by default).

Authenticate each installed vendor CLI independently. Cuttle's optional provider
keys do not log all harnesses in. See README.md for exact dependency commands.

Build from electron/:
  Windows: npm run build / npm run build:dir / npm run build:portable
  Linux:   npm run build:linux / npm run build:linux:dir
Artifacts: electron/dist/, using <version> from package.json.

Do not kill Python to resolve startup or port conflicts. UI close/relaunch keeps
the daemon alive; Host tray Exit explicitly stops a daemon it spawned. Use the
Cuttle Flask restart card for daemon-owned restart. Inspect logs before acting.

Detailed setup: electron/README.md
Troubleshooting: electron/BUILD_TROUBLESHOOTING.md
